# 已知限制

1. **精简后尚未实机验证**：2026-11-16 移除了防火墙、链式代理、DNS-01、多用户、服务账户以及全部备份/快照/回滚机制，并改为以 root 运行服务。这些改动只经过 `bash -n`、ShellCheck 和 Python 编译检查；`tests/run-regression.sh` 需要在 Linux（Bash ≥ 4）上运行，服务端测试需在授权测试 VPS 上重跑。
2. **平台覆盖**：精简前的版本在 Ubuntu 26.10 x86_64 和 Ubuntu 26.04.1 LTS x86_64 上做过实机安装测试；Debian 12/13、Ubuntu 24.04 和 aarch64 没有实机验证。
3. **无自动回滚**：安装、凭据重置、站点更新、升级失败时都不会恢复原状。安装可以重跑继续；其他操作需按 `manage.sh diagnose` 的输出手动处理。卸载不做备份。
4. **原生公网 UDP**：Hysteria2 的公网 UDP 可达性取决于客户端网络和云平台，曾出现个别网络路径不通的情况。
5. **版本升级**：只保证固定版本。升级到其他版本前，需要另行验证与 Mihomo 的兼容性，见 COMPATIBILITY.md。
6. **告警**：续期失败只写日志和 syslog，没有接入邮件、短信或推送。
7. **防火墙**：不由本项目管理。系统防火墙或云安全组须放行 TCP 80/443、UDP 443 和 SSH。
8. **Reality target 耦合**：Nginx 是本地 target，它故障时会影响回退和新的 Reality 握手。
9. **出站过滤**：私网和元数据阻断不是完整的 SSRF 防护，不覆盖 DNS 重绑定及全部特殊地址。本机地址在渲染时采集，公网 IP 变化后需重新渲染。
10. **资源调优**：未做带宽或内核调优，也没有压测基准。
11. **Ubuntu 26.10 生命周期**：短期支持版本，到期后的系统升级路径未验证。

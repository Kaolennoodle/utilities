# 脚本交互菜单设计标准

本仓库交互式脚本的菜单统一遵循以下约定。参考实现：[hy2.sh](../scripts/hy2.sh) 的 `Menus` 部分（`menu_loop` / `build_*`）。

## 1. 画面结构

每次显示菜单都先清屏，然后从上到下依次是：

```text
==============================================
   脚本名  v版本号
   状态: ● 运行中   内核: 2.6.0   开机自启: 是     ← 状态栏：关键状态一行看全
   地址: hy.example.com:443/udp                    ← 已配置时显示核心参数
==============================================
 子菜单标题                                         ← 仅子菜单
 —— 分组 ——
   1. 菜单项
   2. 菜单项  ▶                                     ← ▶ / > 表示进入子菜单
  10. 危险操作                                      ← 红色
----------------------------------------------
   L. 切换语言                                      ← 全局快捷键
   0. 退出 / 返回
==============================================
[WARN] 无效选项: x                                  ← 上一次输入的提示，只显示一次
请选择:
```

- 状态栏颜色：绿色为正常，红色为停止/故障，黄色为未安装/需注意。
- 子菜单沿用同一套头部和底部，只多一行子菜单标题。

## 2. 按状态显示菜单项

- 只列出**当前状态下能执行**的操作，不显示选了只会报“未安装”的项目。
- 状态至少区分三种：**未安装**、**部分安装/非本脚本管理**（只给安装和卸载）、**已安装**（完整菜单）。
- 同一状态下编号固定，方便记忆；状态切换后编号可以变化。
- 互斥操作只显示可用的一个：服务运行中显示“重启 / 停止”，已停止只显示“启动”；已安装时“安装”改为“重新安装”。

## 3. 排序与分组

1. **常用**：查看类、最高频操作（分享链接、状态、日志）。
2. **配置**：修改类操作和子菜单。
3. **维护**：更新、重新安装、卸载，**危险操作始终放在最后**。

- 每组用 `—— 分组名 ——` 标出。一屏菜单项不超过约 12 个，再多就拆成子菜单。
- 修改类菜单项在后面附 `（当前: 值）`，进去之前就能看到现值。

## 4. 编号与按键

| 按键 | 含义 |
| --- | --- |
| `1`–`N` | 菜单项，按显示顺序自动连续编号，分组标题不占编号 |
| `0` | 主菜单为退出，子菜单为返回上一级 |
| `q` | 同 `0`（不在菜单中显示） |
| `L` | 切换界面语言，任何层级都可用 |
| 回车（空输入） | 原样重绘，不提示 |
| Ctrl-D（EOF） | 主菜单退出，子菜单返回 |

- 输入先去掉空格并转小写，` 1 `、`L` 都能识别。
- 字母只用于全局快捷键，菜单项一律用数字。

## 5. 交互反馈

- **执行操作后暂停**（“按回车继续”），让输出在清屏前能被看完。
- **导航不暂停**：进入/返回子菜单、切换语言、空输入、无效输入都直接重绘。
- **无效输入**在重绘后的菜单底部提示一次，不需要额外按回车。
- 子菜单返回失败（如前置检查不通过）时暂停，保证错误信息可见。
- 操作失败返回非零并打印原因，菜单继续运行；除“退出”和“卸载”外，任何操作都不直接结束脚本。

## 6. 确认与危险操作

- 危险操作：卸载、重新安装、覆盖配置、删除数据、强制重新申请证书等。菜单中红色显示，归入最后一组。
- 执行前说明后果并确认，**默认选“否”**（`[y/N]`）；常规的“继续安装？”可以默认“是”（`[Y/n]`）。
- 修改前备份，失败时自动恢复，并告诉用户已恢复。
- 改动后与原值相同时提示“未修改”，不重启服务。

## 7. 实现约定

- 菜单由“构建函数”声明当前状态下的菜单项（`menu_section` / `menu_item 类型 函数 文本`），由公共的 `menu_loop` 负责渲染、读取、分发。每轮循环重新构建，保证状态和当前值实时更新。
- 菜单项类型：`act` 普通操作（执行后暂停）、`sub` 子菜单（不暂停）、`danger` 危险操作（红色，执行后暂停）。
- 每个菜单项对应一个独立函数，不在 `case` 里写多行逻辑。
- 所有文字都通过 `t key` 取翻译，中英文条目同步添加。
- 只在有终端时进入菜单；常用操作同时提供命令行子命令（如 `hy2 link`、`hy2 status`），方便脚本化和无终端环境。
- 支持 `curl ... | bash` 运行：输入从 `/dev/tty` 读取，不依赖 `$0` 定位脚本自身（见 README 的“说明”）。
